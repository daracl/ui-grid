API 레퍼런스

HeaderOptions

헤더 행을 제어합니다: 표시 여부, 높이, 정렬, 컬럼 리사이즈, 전체 선택, 도움말 버튼, 컬럼 드래그.

소스: src/types/GridOptions.d.ts, src/defaultGridOption.ts

타입

interface HeaderOptions {
  view: boolean;
  height: number | number[];
  sort: SortOption;
  resize: HeaderResize;
  enabledAllColumnSelection: boolean;
  enabledScroll: boolean;
  enabledViewAllLabel: boolean;
  help: {
    enabled: boolean;
    content: string | OptionCallback;
    click?: OptionCallback;
    showDelay: number;
  };
  drag: {
    enabled?: boolean;
    dropSelector?: string;
    dropCallback?: boolean | OptionCallback;
  };
}
