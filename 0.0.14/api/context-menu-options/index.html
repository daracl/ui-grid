ContextMenuOptions

Configures the right-click context menu. Set as GridOptions.contextMenu (not set by default).

Source: src/types/ContenxtMenu.d.ts

Type

interface ContextMenuOptions {
  beforeActivate: OptionCallback;
  disableItem: OptionCallback;
  callback: OptionCallback;
  items: ContextMenuItem[];
  enabledHeader: boolean;
}

interface ContextMenuItem {
  header?: string;
  key?: string;
  disabled?: boolean;
  hotkey?: string;
  label: string;
  checkbox?: boolean;
  callback?: OptionCallback;
  itemClass?: string | OptionCallback;
  divider?: boolean;
  children?: ContextMenuItem[];
}

Properties

PropertyTypeDefaultDescription
beforeActivateOptionCallback—Called before the menu opens; can be used to adjust items dynamically.
disableItemOptionCallback—Called to determine which items should be disabled when the menu opens.
callbackOptionCallback—Called with the clicked item when a menu item is selected.
itemsContextMenuItem[]—Menu item tree.
enabledHeaderboolean—Enables the context menu on the header row as well as the body.
item.labelstring—ContextMenuItem — text shown for the item.
item.key?string—ContextMenuItem — identifier passed back in callbacks.
item.hotkey?string—ContextMenuItem — hotkey hint text displayed next to the label.
item.checkbox?boolean—ContextMenuItem — renders the item as a checkbox toggle.
item.divider?boolean—ContextMenuItem — renders a separator line instead of a clickable item.
item.children?ContextMenuItem[]—ContextMenuItem — nested submenu items.

Example

contextMenu: {
  enabledHeader: false,
  items: [
    { key: 'copy', label: 'Copy' },
    { divider: true },
    { key: 'delete', label: 'Delete row' },
  ],
  callback: (item) => console.log('menu click', item.key),
}
