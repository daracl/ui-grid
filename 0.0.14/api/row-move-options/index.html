API Reference

RowMoveOptions

Configures row drag & drop reordering, including tree re-parenting. Set as GridOptions.body.rowMove.

Source: src/types/GridOptions.d.ts, src/defaultGridOption.ts

Type

interface RowMoveOptions {
  enabled: boolean;
  enabledDragHandle?: boolean;
  dragHandle?: string;
  draggable?: (rowData: any, rowIndex: number) => boolean;
  allowChangeParent?: boolean;
  dragStart?: (params: { moveItems: any[] }) => boolean | void;
  dragOver?: (params: RowMoveEventParams) => boolean | void;
  drop?: (params: RowMoveEventParams) => boolean | void;
  dragEnd?: (params: RowMoveEventParams) => boolean | void;
  dragTemplate?: OptionCallback;
}

interface RowMoveEventParams {
  moveItems: any[];
  dropItemIdx: number;
  position: 'before' | 'after' | 'inside';
}

Properties

enabledDragHandle?boolean—Restricts dragging to a handle element rather than the whole row.
dragHandle?string—Field name whose cell acts as the drag handle.
draggable?(rowData: any, rowIndex: number) => boolean—Dynamically controls whether a given row can be dragged.
allowChangeParent?booleanfalseIn tree mode, allows a dragged row to be dropped under a different parent.
dragStart?(params: { moveItems: any[] }) => boolean | void—Called when a drag begins. `params.moveItems` is the array of rows being dragged. Returning false cancels the drag.
dragOver?(params: RowMoveEventParams) => boolean | void—Called while dragging over a potential drop target. `params.dropItemIdx` is the row index under the pointer, `params.position` is before/after/inside. Returning false disallows dropping there.
drop?(params: RowMoveEventParams) => boolean | void—Called when the drop occurs. Returning false cancels the drop and the row(s) return to their original position.
dragEnd?(params: RowMoveEventParams) => boolean | void—Called after the drag ends, regardless of whether the drop succeeded.
dragTemplate?OptionCallback—Renders custom HTML/content for the drag ghost element.

Example

body: {
  rowMove: {
    enabled: true,
    dragHandle: 'name',
    dragOver: ({ dropItemIdx, position }) => {
      // return false to forbid dropping at this position
    },
    drop: ({ moveItems, dropItemIdx, position }) => {
      console.log('dropped', moveItems, dropItemIdx, position);
    },
  },
}
