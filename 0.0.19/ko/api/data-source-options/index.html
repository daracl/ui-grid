API 레퍼런스

DataSourceOptions

GridOptions.dataSource에 지정하는 서버 조회·저장·삭제, 서버 페이징 및 무한 스크롤 설정입니다. HTTP 조회는 GET, 저장·삭제는 POST가 기본입니다. 생략하면 로컬 데이터를 사용합니다.

소스: src/types/DataSource.d.ts

타입

interface DataSourceOptions {
  load?: HttpEndpoint | LoadFunction;
  save?: HttpEndpoint | SaveFunction;
  remove?: HttpEndpoint | RemoveFunction;

  baseUrl?: string;
  headers?: HttpHeaders | (() => HttpHeaders | Promise<HttpHeaders>);
  credentials?: RequestCredentials;
  timeout?: number;
  fetchMode?: 'fetch' | 'xhr';
  autoLoad?: boolean;
  toolbarParams?: boolean;
  loader?: false | DataSourceLoader;
  request?: (request: HttpRequest) => Promise<unknown>;

  requestMap?: (data: any, operation: DataSourceOperation) => unknown;
  responseFilter?: (response: any, operation: DataSourceOperation, info: ResponseInfo) => unknown | Promise<unknown>;
  errorFilter?: (error: DataSourceError, operation: DataSourceOperation, info: ErrorInfo) => unknown | Promise<unknown>;
  responseMap?: (response: any, operation: DataSourceOperation) => unknown;

  paging?: {
    mode: 'local' | 'server' | 'infinite';
    pageSize?: number;
    threshold?: number;
  };
  sorting?: { mode: 'local' | 'server' };
  filtering?: { mode: 'local' | 'server' };

  events?: DataSourceEvents;
}

속성

속성타입기본값설명
load?HttpEndpoint | LoadFunction—HTTP 주소 또는 조회 함수입니다. 함수는 조건과 AbortSignal을 받고 { items, total? }을 반환합니다.
save?HttpEndpoint | SaveFunction—HTTP 주소 또는 저장 함수입니다. { created, updated, deleted }를 받고 신규 ID의 idMap과 실패 행 ID의 failed를 반환할 수 있습니다. soft 삭제 방식이 필요합니다.
remove?HttpEndpoint | RemoveFunction—HTTP 주소 또는 삭제 함수입니다. { deleted }를 받습니다.
baseUrl?string—상대 URL 앞에 붙는 공통 주소
headers?HttpHeaders | (() => HttpHeaders | Promise<HttpHeaders>)—공통 헤더. 함수이면 요청마다 호출하므로 인증 토큰 갱신에 사용할 수 있다.
credentials?RequestCredentials—HTTP 요청의 자격 증명 전송 정책입니다.
timeout?number—HTTP 요청 제한 시간(ms)입니다.
fetchMode?'fetch' | 'xhr'—코어 Ajax 전송 방식
autoLoad?boolean—그리드 생성 직후 load()를 자동 실행한다. 툴바 사용 여부와 무관하며 dataSource.load가 필요하다. 조회 조건은 툴바 값(툴바가 있을 때)만 사용하고, 실패는 loadError 이벤트로 알린다.
toolbarParams?boolean—load()·searchRemote() 호출 시 툴바 필드 값을 조회 조건에 포함한다. 같은 이름의 명시 조건이 우선한다.
loader?false | DataSourceLoader—HTTP 요청 중 코어 Ajax 로더 표시 설정. false이면 표시하지 않는다.
request?(request: HttpRequest) => Promise<unknown>—코어 Ajax 대신 사용할 HTTP 전송 함수. 응답 본문(JSON)을 resolve한다.
requestMap?(data: any, operation: DataSourceOperation) => unknown—HTTP 요청 데이터 변환. 반환값이 조회 쿼리 또는 저장·삭제 본문이 된다.
responseFilter?(response: any, operation: DataSourceOperation, info: ResponseInfo) => unknown | Promise<unknown>—HTTP 응답 검사·정리. responseMap보다 먼저 호출되며 반환값이 responseMap(없으면 검증)에 전달된다. - 성공 응답: 응답 봉투(`{ code, message, data }`) 검사·해제 등에 사용한다. - 상태 코드 오류(2xx 외: 401/403/404/500 등): errorFilter가 없을 때만(호환용, errorFilter 사용 권장) `info.ok`가 false로 호출되며 `response`는 응답 본문(JSON이면 파싱한 값)이다. 값을 반환하면 오류가 복구되어 정상 응답처럼 이어지고(예: 404 → `{ items: [] }`), 던지면 그 오류가 전달되며, `info.error`를 던지면 기본 HTTP 오류가 그대로 전달된다. responseFilter가 없으면 기본적으로 HTTP 오류로 reject된다. - 연결 실패·timeout·취소는 응답이 없으므로 호출하지 않는다. 던진 오류는(DataSourceError가 아니면 INVALID_RESPONSE로 변환되어) loadError/saveError/removeError 이벤트와 reject로 전달된다. HTTP 설정에만 적용된다.
errorFilter?(error: DataSourceError, operation: DataSourceOperation, info: ErrorInfo) => unknown | Promise<unknown>—HTTP 오류 처리. 상태 코드 오류(HTTP)와 연결 실패(NETWORK)·timeout(TIMEOUT)에서 호출되며 취소(ABORT)는 호출하지 않는다. - 값을 반환하면 오류가 복구되어 정상 응답처럼 responseMap(없으면 검증)으로 이어진다(responseFilter는 호출하지 않는다). - 던진 오류는 그대로 전달되고, DataSourceError가 아니면 원래 오류의 code·status를 유지한 채 메시지만 바뀐다. `error`를 그대로 던지면 기본 동작과 같다. - 복구하면 loadError/saveError/removeError 이벤트는 발생하지 않는다. - errorFilter가 없으면 상태 코드 오류는 responseFilter(`info.ok === false`)로 전달된다(호환용). HTTP 설정에만 적용된다.
responseMap?(response: any, operation: DataSourceOperation) => unknown—HTTP 응답 변환. load는 LoadResult, save는 SaveResult를 반환해야 한다.
paging.mode'local' | 'server' | 'infinite'—local·server·infinite 페이징 방식입니다. 서버·무한 스크롤은 목록 모드만 지원합니다. server는 footer.enabled와 footer.paging.enabled가 필요합니다. infinite는 페이지 버튼 없이 이어 붙이며 검색·정렬·재조회 시 첫 페이지부터 조회합니다. 저장·삭제 성공 후 미저장 변경이 없으면 재조회합니다.
paging.pageSize?number—페이지당 요청 건수입니다. page·pageSize를 전송하며 무한 스크롤은 total 또는 요청보다 적은 응답 건수로 끝을 판단합니다.
paging.threshold?number—infinite: 화면 끝에서 이 행 수 이내로 스크롤하면 다음 페이지를 조회한다. @default 5
sorting.mode'local' | 'server'—기본 local 또는 server입니다. 서버 정렬은 헤더 순서대로 sort 배열을 보내고 첫 페이지부터 조회합니다. 명시 조건의 sort보다 헤더 정렬이 우선하며 트리·그룹에서는 사용할 수 없습니다.
filtering.mode'local' | 'server'—local만 지원하며 server를 지정하면 오류가 발생합니다.
events?DataSourceEvents—beforeLoad·beforeSave·beforeRemove에서 false 또는 Promise<false>를 반환하면 취소합니다. 완료는 load·save·remove, 오류는 loadError·saveError·removeError, 로딩 상태는 loadingChange로 알립니다. 공통으로 grid와 operation을 제공합니다.
