Basic
Basic Grid

The smallest working grid: a set of column definitions (`fields`) and row data (`items`).

Selection
Selection

GridOptions.selectionMode controls how cells/rows can be selected. Switch modes below to see the difference.

Editing
Editing

GridOptions.editable turns on inline cell editing. Each field chooses its own editRenderer (number, dropdown, switch, …).

Sorting
Sorting

header.sort.enabled turns sortable-header behavior on for every column grid-wide. A column can also opt in on its own with field.sort: true, independent of this switch.

Paging
Paging

GridOptions.paging holds the client-side paging state; footer.paging renders the page range text in the footer bar.

Footer
Footer

FooterOptions combines a paging indicator and a selection summary in the same bar. Try selecting cells to see the summary update.

Toolbar
Toolbar

ToolbarOptions.items lays out rows of left/right item groups above the grid — buttons, dropdowns, text, search and more.

Tree
Tree Grid

GridOptions.tree turns the grid into a tree grid. This example uses flat rows (id/parentId) with isFlatData: true, plus expandDepth and defaultExpandedIds.

Row Move
Row Move

body.rowMove enables drag & drop row reordering. dragStart / dragOver / drop / dragEnd each receive the rows being moved and the drop position.
