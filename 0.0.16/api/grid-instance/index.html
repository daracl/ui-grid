API Reference

DaraGrid (instance API)

Public methods available on a DaraGrid instance created via `DaraGrid.create(element, options)` or `new DaraGrid(element, options)`.

Source: src/DaraGrid.ts

Type

class DaraGrid {
  static VERSION: string;
  constructor(gridElement: HTMLElement, options: GridOptions, message?: Message);
  static create(gridElement: HTMLElement, options: GridOptions, message?: Message): DaraGrid;
  static instance(eleOrId: HTMLElement | string): DaraGrid | null;
  static message(message: Message): void;
  static setIcons(icons: any): void;

  getOptions(): GridOptions;
  instanceId(): string;
  getFields(): FieldItem[];
  getItems(): any[];
  hideLayer(): void;
  setFocusOut(): void;
  getToolbarValues(): any;
  setToolbarValues(values: any): void;
  getItemsByIndexs(indexs: number[]): any[];
  selectRowById(rowId: RowId, opts: RowSelectOptions): void;
  getItemById(rowId: RowId): any;
  getItemsByIds(rowIds: RowId[]): any[];
  setPaging(paging: PagingInfo): void;
  setItems(items: any[]): void;
  clearItems(): void;
  addItems(items: any[], addOpts?: AddRowOptions): void;
  createItem(item: any, addOpts?: AddRowOptions): void;
  removeItems(ids: any[]): void;
  setSize(width: number, height: number): void;
  getSelection(numberFieldSummary?: boolean): any;
  getSelectedRows(): any[];
  getSelectedRowIds(): RowId[];
  getCheckedItems(names?: string | string[]): any;
  getCheckedIds(): any[];
  getCheckedItemByName(name: string): any[];
  setAllCheckedItems(checked: boolean): void;
  setCheckedItemByValue(name: string, values: any): void;
  addCheckedItemByValue(name: string, values: any): void;
  unCheckedItemByValue(name: string, values: any): void;
  getChangedItems(): any[];
  setTheme(themeName?: ThemeType | ''): void;
  setStyle(styleName: BodyStyle): void;
  getGridHeight(): number;
  copyData(): void;
  changeContextMenuHeader(label: string): void;
  expandAll(): void;
  collapseAll(): void;
  search(searchText: string, opts: SearchMode): any;
  destroy(): void;
}

Properties

PropertyTypeDefaultDescription
createstatic (element, options, message?) => DaraGrid—Creates and returns a new grid instance mounted in `element`.
instancestatic (elementOrId) => DaraGrid | null—Looks up a previously created grid instance by its container element or instance id.
messagestatic (message: Message) => void—Sets the global i18n message dictionary used by every grid instance.
setIconsstatic (icons: any) => void—Overrides the built-in icon set (e.g. toolbar button icons) used by every grid instance.
getOptions() => GridOptions—Returns the fully-merged GridOptions currently in effect.
instanceId() => string—Returns this grid instance's unique id, used by DaraGrid.instance() to look it up again.
getFields() => FieldItem[]—Returns the current column (FieldItem) definitions.
getItems() => any[]—Returns all row data currently in the grid.
setItems(items: any[]) => void—Replaces all row data.
clearItems() => void—Removes all rows.
addItems(items: any[], addOpts?: AddRowOptions) => void—Adds rows. `addOpts` = { rowId?, position?: 'before' | 'after' | 'inside' } to target a specific existing row (e.g. for tree insertion).
createItem(item: any, addOpts?: AddRowOptions) => void—Adds a single new row, same positioning semantics as addItems.
removeItems(ids: any[]) => void—Removes rows by their row-id values.
getChangedItems() => any[]—Returns only rows with a pending create/update/delete state.
setPaging(paging: PagingInfo) => void—Updates the paging state used by the footer/paging UI.
getItemById(rowId: RowId) => any—Looks up a row by its row id.
getItemsByIds(rowIds: RowId[]) => any[]—Looks up rows by row id.
getItemsByIndexs(indexs: number[]) => any[]—Looks up row data by view-row index.
selectRowById(rowId: RowId, opts: RowSelectOptions) => void—Programmatically selects a row by id; `opts.scrollIntoView` controls auto-scroll.
getSelection(numberFieldSummary?: boolean) => any—Returns the current selection data (and optional numeric-field summary) based on selectionMode.
getSelectedRows() => any[]—Returns the currently selected row objects.
getSelectedRowIds() => RowId[]—Returns the currently selected row ids.
getCheckedItems(names?: string | string[]) => any—Returns checked-row data, optionally limited to given field names.
getCheckedIds() => any[]—Returns checked-row ids.
getCheckedItemByName(name: string) => any[]—Returns the given field's value for every currently checked row, e.g. name: 'id' returns the checked rows' ids.
setAllCheckedItems(checked: boolean) => void—Checks or unchecks every row.
setCheckedItemByValue(name: string, values: any) => void—Sets the checked state for rows whose `name` field matches `values`.
addCheckedItemByValue(name: string, values: any) => void—Adds to the checked state for rows whose `name` field matches `values`.
unCheckedItemByValue(name: string, values: any) => void—Clears the checked state for rows whose `name` field matches `values`.
setTheme(themeName?: ThemeType | '') => void—Switches the grid theme ('light' | 'dark') at runtime. Call it with no argument to clear the per-grid theme and follow the data-daracl-theme attribute again.
setStyle(styleName: BodyStyle) => void—Switches the body style preset at runtime.
setSize(width: number, height: number) => void—Resizes the grid programmatically.
expandAll() => void—Expands every tree node (tree mode only).
collapseAll() => void—Collapses every tree node (tree mode only).
search(searchText: string, opts: SearchMode) => any—Runs a search programmatically with the same options shape as SearchOptions.
copyData() => void—Copies the current selection to the clipboard.
changeContextMenuHeader(label: string) => void—Updates the context menu header label at runtime.
getToolbarValues() => any—Reads the current toolbar item values.
setToolbarValues(values: any) => void—Writes toolbar item values.
getGridHeight() => number—Returns the grid's current rendered height in pixels.
hideLayer() => void—Closes any open floating layer (dropdown/popup/etc).
setFocusOut() => void—Runs the grid's focus-out handling (e.g. closing open layers) as if the grid had lost focus.
destroy() => void—Tears down the grid instance and its DOM/listeners.

Example

const grid = DaraGrid.create(el, options);

grid.setItems(newItems);
const selected = grid.getSelectedRows();
grid.setTheme('dark');
grid.destroy();
