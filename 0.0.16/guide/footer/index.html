Footer

FooterOptions renders a bottom bar combining a paging indicator and a selection summary.

Enable / disable

footer.enabled turns the whole bar on; it is false by default.

footer: { enabled: true, height: 35 }

Paging

footer.paging shows the current page range. format supports {{start}}, {{end}}, {{total}} placeholders.

footer: {
  enabled: true,
  paging: { enabled: true, position: 'center', format: '{{start}} - {{end}} of {{total}}' },
}

Selection & selection summary

footer.selection shows selection info. Its default format uses {{count}}, {{avg}}, {{min}}, {{max}}, {{sum}} — the numeric ones only make sense when the selection covers numeric columns, which showSummary toggles.

footer: {
  enabled: true,
  selection: {
    position: 'left',
    format: 'Count : {{count}} {{if(enabledSummary)}} Sum : {{sum}}{{/if}}',
    showSummary: true,
  },
}
