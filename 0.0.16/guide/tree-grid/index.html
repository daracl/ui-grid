Tree Grid

Set GridOptions.tree to switch the grid into hierarchical mode. Data can be flat rows or already-nested children arrays.

Flat data

Set isFlatData: true and the grid builds the hierarchy from idField / parentIdField on each row (as used in the preview above).

tree: {
  idField: 'id',
  parentIdField: 'parentId',
  isFlatData: true,
  expandDepth: 1,
  defaultExpandedIds: ['1-1'],
},
fields: [{ name: 'name', label: 'Name', renderer: { type: 'tree' } }, /* ... */],
items: [
  { id: '1', parentId: null, name: 'src', type: 'folder' },
  { id: '1-1', parentId: '1', name: 'components', type: 'folder' },
  { id: '1-1-1', parentId: '1-1', name: 'Button.tsx', type: 'file' },
],

Nested (tree) data

Without isFlatData, rows already contain their children in childrenField (default 'children').

tree: { idField: 'id', parentIdField: 'parentId' }, // childrenField defaults to 'children'
items: [
  { id: '1', name: 'src', type: 'folder', children: [
    { id: '1-1', name: 'Button.tsx', type: 'file', size: '2.1kb' },
  ] },
  { id: '2', name: 'package.json', type: 'file', size: '1.8kb' },
],

All TreeOptions

  • idField / parentIdField — the row-identity and parent-reference fields.
  • childrenField — where nested children live (default 'children').
  • expandDepth — depth auto-expanded on first render.
  • defaultExpandedIds — specific row ids expanded initially (takes precedence over expandDepth).
  • treeNodeIconClass — returns a CSS class per node based on its state.
  • grid.expandAll() / grid.collapseAll() — expand or collapse every node.
