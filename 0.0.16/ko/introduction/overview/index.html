개요

Dara Grid(@daracl/grid)는 프레임워크에 종속되지 않는, 의존성 없는 TypeScript 데이터 그리드 라이브러리입니다.

Dara Grid는 컬럼 정의 목록(fields)과 행 데이터 목록(items)이라는 두 가지 입력만으로 데이터 그리드를 렌더링합니다. React, Vue 등 어떤 프레임워크에도 런타임 의존성이 없어서, 순수 스크립트 태그부터 번들러 기반 앱, 사용 중인 프레임워크의 컴포넌트로 감싸는 형태까지 어떤 웹 프로젝트에도 바로 넣을 수 있습니다.

핵심 개념

  • GridOptions — DaraGrid.create(element, options)에 전달하는 단 하나의 객체로, 컬럼·데이터·선택·편집·페이징·툴바 등 모든 것을 설정합니다. 자세히 보기: GridOptions.
  • 필드 — 각 컬럼은 행 객체의 속성과 매칭되는 name과 표시용 label을 가진 FieldItem입니다. 자세히 보기: GridField.
  • 렌더러 — 각 필드는 서로 다른 보기 렌더러(어떻게 보여줄지)와 편집 렌더러(어떻게 편집할지)를 사용할 수 있습니다. 예: text, number, dropdown, switch, date.
  • 목록형 vs. 트리형 — 그리드는 기본적으로 평면 행 데이터를 렌더링합니다. GridOptions.tree를 설정하면 동일한 fields/렌더러를 그대로 사용하면서 계층형 트리 모드로 전환됩니다.

인스턴스 API

DaraGrid.create()는 그리드가 존재하는 동안 계속 참조해서 쓰는 인스턴스를 반환합니다 — grid.setItems(), grid.getSelectedRows(), grid.setTheme(), grid.destroy() 등을 제공합니다. 자세히 보기: DaraGrid (instance API).
