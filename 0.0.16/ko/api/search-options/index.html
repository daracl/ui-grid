SearchOptions

그리드에 내장된 검색/필터 패널(GridOptions.search)을 설정합니다. 이는 그리드의 유일한 텍스트 필터링 기능이며, 현재 소스에는 별도의 컬럼 필터 API가 없습니다.

소스: src/types/GridOptions.d.ts, src/defaultGridOption.ts

타입

interface SearchOptions {
  enabled?: boolean;
  matchWholeRegex?: RegExp;
  hideNonMatched?: boolean;
  mode?: 'simple' | 'full';
  enabledColumnFix?: boolean;
  click?: boolean | OptionCallback;
  onlyCloseButton?: boolean;
  useRememberValue?: boolean;
  width?: number;
  height?: number;
  callback?: boolean | OptionCallback;
  rememberValue?: { field?: string; keyword?: string };
}

속성

속성타입기본값설명
enabled?booleanfalse검색 패널을 활성화합니다.
matchWholeRegex?RegExp—검색어가 단어/토큰 전체와 일치하는지 검사하는 정규식입니다.
hideNonMatched?booleanfalse일치 항목만 강조하는 대신, 검색과 일치하지 않는 행을 아예 숨깁니다.
mode?'simple' | 'full''simple'검색 UI 모드입니다 — 간단한 바(simple) 또는 더 많은 옵션을 가진 확장 패널(full).
enabledColumnFix?boolean—검색 대상을 고정된 컬럼 집합으로 제한하는 기능을 활성화합니다.
click?boolean | OptionCallbackfalse설정하면 내장 로직 대신 이 콜백이 검색 실행을 전담합니다.
onlyCloseButton?booleanfalse검색 패널을 닫기 버튼으로만 닫을 수 있도록 제한합니다.
useRememberValue?booleanfalse마지막 검색 필드/검색어를 로컬 스토리지에 저장합니다.
width?number250검색 패널 너비(px)입니다.
height?number30검색 패널 높이(px)입니다.
callback?boolean | OptionCallbackfalse검색 실행 후 결과와 함께 호출됩니다.
rememberValue.field?string''초기값 또는 저장된 검색 필드입니다.
rememberValue.keyword?string''초기값 또는 저장된 검색어입니다.
