API 레퍼런스

ScrollOptions

세로 및 가로 스크롤 동작을 설정합니다.

소스: src/types/GridOptions.d.ts, src/defaultGridOption.ts

타입

interface ScrollOptions {
  enabledWheelInContainer?: boolean;
  width: number;
  vertical: {
    enabled: boolean;
    speed: number;
    onUpdate?: OptionCallback;
    enabledTooltip: boolean;
  };
  horizontal: {
    enabled: boolean;
    speed: number;
    enabledWheel: boolean;
    onUpdate: OptionCallback | boolean;
  };
}

속성

속성타입기본값설명
enabledWheelInContainer?booleanfalse휠 스크롤 이벤트가 그리드 컨테이너 밖으로 전파되지 않도록 합니다.
widthnumber12스크롤바 두께(px)입니다.
vertical.enabledbooleantrue세로 스크롤을 활성화합니다.
vertical.speednumber3휠 한 틱당 스크롤되는 행 수입니다.
vertical.onUpdate?OptionCallback() => true세로 스크롤 위치가 변경될 때 호출됩니다.
vertical.enabledTooltipbooleanfalse스크롤 중 현재 행 개수를 보여주는 툴팁을 표시합니다.
horizontal.enabledbooleantrue가로 스크롤을 활성화합니다.
horizontal.speednumber1가로 스크롤 속도 배수입니다.
horizontal.enabledWheelbooleanfalse마우스 휠로 가로 스크롤을 이동할 수 있게 합니다.
horizontal.onUpdateOptionCallback | booleanfalse가로 스크롤 위치가 변경될 때 호출됩니다.

상세

enabledWheelInContainerboolean선택기본값: false

휠 스크롤 이벤트가 그리드 컨테이너 밖으로 전파되지 않도록 합니다.

widthnumber필수기본값: 12

스크롤바 두께(px)입니다.

vertical
enabledboolean필수기본값: true

세로 스크롤을 활성화합니다.

speednumber필수기본값: 3

휠 한 틱당 스크롤되는 행 수입니다.

onUpdateOptionCallback선택기본값: () => true

세로 스크롤 위치가 변경될 때 호출됩니다.

enabledTooltipboolean필수기본값: false

스크롤 중 현재 행 개수를 보여주는 툴팁을 표시합니다.

horizontal
enabledboolean필수기본값: true

가로 스크롤을 활성화합니다.

speednumber필수기본값: 1

가로 스크롤 속도 배수입니다.

enabledWheelboolean필수기본값: false

마우스 휠로 가로 스크롤을 이동할 수 있게 합니다.

onUpdateOptionCallback | boolean필수기본값: false

가로 스크롤 위치가 변경될 때 호출됩니다.

  vertical: { enabled: true, speed: 3 },
