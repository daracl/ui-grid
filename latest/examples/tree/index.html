Tree Example

Tree Grid

GridOptions.tree turns the grid into a tree grid. This example uses flat rows (id/parentId) with isFlatData: true, plus expandDepth and defaultExpandedIds.

TreeOptions →Tree Grid guide →

Preview

View source
