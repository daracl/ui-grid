# UI 예제 데이터

- `employee*.js`, `tree*.js`, `dropdown.js`: 직원·조직·선택 항목 데이터와 기존 컬럼 정의.
- `businessFixtures.js`: 업무 화면에 사용할 가상 상품·거래처·주문번호·지역 값. 실제 개인정보가 아니다.
- `examples/`: 예제 파일별 컬럼 정의, 데이터 및 생성 함수. 필드 키·값 타입·행 수·트리 계층·병합 패턴은 각 예제의 목적에 맞게 유지한다.
- `builder/`: 빌더에서 선택하는 JSON 데이터 세트와 설정.

화면 이벤트와 그리드 생성 코드는 `uitest/asset/pages/`에 둔다. HTML에는 데이터 배열이나 컬럼 정의를 직접 작성하지 않는다.

기존 전역 API를 사용하는 예제의 데이터 스크립트는 일반 script로 로드한다. 모듈 예제는 필요한 정의만 import한다. `businessFixtures.js`는 업무 데이터 생성 함수를 사용하기 전에 로드해야 한다. 데이터는 그리드가 내부 메타데이터를 추가할 수 있으므로, 반복 생성하는 예제에서는 매번 새로운 행·컬럼 객체를 생성한다.
