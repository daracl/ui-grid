Introduction

Installation

Install @daracl/grid with your package manager of choice, or load it via a script tag.

Package manager

yarn add @daracl/grid
# or
npm install @daracl/grid

ESM / bundler usage

Import DaraGrid and its stylesheet, then call DaraGrid.create() against a container element.

import { DaraGrid } from '@daracl/grid';
import type { GridOptions } from '@daracl/grid';
import '@daracl/grid/style/daracl.grid.css';

const grid = DaraGrid.create(document.getElementById('grid')!, {
  fields: [{ name: 'name', label: 'Name' }],
  items: [{ name: 'John' }],
} as GridOptions);

UMD / script tag

Without a bundler, load the UMD build and stylesheet directly; the library registers itself as window.Daracl.grid.

<link rel="stylesheet" href="./node_modules/@daracl/grid/style/daracl.grid.min.css" />
<script src="./node_modules/@daracl/grid/dist/daracl.grid.min.umd.js"></script>
<script>
  const grid = Daracl.grid.create(document.getElementById('grid'), {
    fields: [{ name: 'name', label: 'Name' }],
    items: [{ name: 'John' }],
  });
</script>

Importing the UMD build directly

If your bundler resolves @daracl/grid/umd (mapped to dist/daracl.grid.umd.js) and you import it instead of using a plain <script> tag, import it for its side effect only — it registers window.Daracl.grid, the same global the script-tag version uses.

import '@daracl/grid/umd';
import '@daracl/grid/style/daracl.grid.css';

// Registers window.Daracl.grid as a side effect — see the note below.
const grid = window.Daracl.grid.create(document.getElementById('grid'), {
  fields: [{ name: 'name', label: 'Name' }],
  items: [{ name: 'John' }],
});

CDN

No install step at all: load the published package straight from a CDN.

jsDelivr
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@daracl/grid/style/daracl.grid.min.css" />
<script src="https://cdn.jsdelivr.net/npm/@daracl/grid/dist/daracl.grid.min.umd.js"></script>
<script>
  const grid = Daracl.grid.create(document.getElementById('grid'), {
    fields: [{ name: 'name', label: 'Name' }],
    items: [{ name: 'John' }],
  });
</script>

Alternative: unpkg

unpkg
<link rel="stylesheet" href="https://unpkg.com/@daracl/grid/style/daracl.grid.min.css" />
<script src="https://unpkg.com/@daracl/grid/dist/daracl.grid.min.umd.js"></script>

Both URLs above resolve to the latest published version. Pin an exact version for production use, e.g. .../@daracl/grid@0.0.7/....
