API 레퍼런스

DaraGrid (instance API)

`DaraGrid.create(element, options)` 또는 `new DaraGrid(element, options)`로 생성한 DaraGrid 인스턴스에서 사용할 수 있는 공개 메소드입니다.

소스: src/DaraGrid.ts

타입

class DaraGrid {
  static VERSION: string;
  constructor(gridElement: HTMLElement, options: GridOptions, message?: Message);
  static create(gridElement: HTMLElement, options: GridOptions, message?: Message): DaraGrid;
  static instance(eleOrId: HTMLElement | string): DaraGrid | null;
  static message(message: Message): void;
  static setIcons(icons: any): void;

  getOptions(): GridOptions;
  instanceId(): string;
  getFields(): FieldItem[];
  getItems(): any[];
  hideLayer(): void;
  setFocusOut(): void;
  getToolbarValues(): any;
  setToolbarValues(values: any): void;
  getItemsByIndexs(indexs: number[]): any[];
  selectRowById(rowId: RowId, opts: RowSelectOptions): void;
  getItemById(rowId: RowId): any;
  getItemsByIds(rowIds: RowId[]): any[];
  setPaging(paging: PagingInfo): void;
  setItems(items: any[]): void;
  clearItems(): void;
  addItems(items: any[], addOpts?: AddRowOptions): void;
  createItem(item: any, addOpts?: AddRowOptions): void;
  removeItems(ids: any[]): void;
  setSize(width: number, height: number): void;
  getSelection(numberFieldSummary?: boolean): any;
  getSelectedRows(): any[];
  getSelectedRowIds(): RowId[];
  getCheckedItems(names?: string | string[]): any;
  getCheckedIds(): any[];
  getCheckedItemByName(name: string): any[];
  setAllCheckedItems(checked: boolean): void;
  setCheckedItemByValue(name: string, values: any): void;
  addCheckedItemByValue(name: string, values: any): void;
  unCheckedItemByValue(name: string, values: any): void;
  getChangedItems(): any[];
  setTheme(themeName?: ThemeType | ''): void;
  setStyle(styleName: BodyStyle): void;
  getGridHeight(): number;
  copyData(): void;
  changeContextMenuHeader(label: string): void;
  expandAll(): void;
  collapseAll(): void;
  search(searchText: string, opts: SearchMode): any;
  destroy(): void;
}

속성

속성타입기본값설명
createstatic (element, options, message?) => DaraGrid—`element`에 마운트된 새 그리드 인스턴스를 생성하여 반환합니다.
instancestatic (elementOrId) => DaraGrid | null—컨테이너 엘리먼트 또는 인스턴스 id로 이전에 생성된 그리드 인스턴스를 찾습니다.
messagestatic (message: Message) => void—모든 그리드 인스턴스가 사용하는 전역 i18n 메시지 사전을 설정합니다.
setIconsstatic (icons: any) => void—모든 그리드 인스턴스가 사용하는 내장 아이콘 세트(예: 툴바 버튼 아이콘)를 덮어씁니다.
getOptions() => GridOptions—현재 적용 중인, 완전히 병합된 GridOptions를 반환합니다.
instanceId() => string—DaraGrid.instance()로 다시 조회할 때 사용하는, 이 그리드 인스턴스의 고유 id를 반환합니다.
getFields() => FieldItem[]—현재 컬럼(FieldItem) 정의를 반환합니다.
getItems() => any[]—그리드에 있는 전체 행 데이터를 반환합니다.
setItems(items: any[]) => void—전체 행 데이터를 교체합니다.
clearItems() => void—모든 행을 제거합니다.
addItems(items: any[], addOpts?: AddRowOptions) => void—행을 추가합니다. `addOpts` = { rowId?, position?: 'before' | 'after' | 'inside' }로 기존의 특정 행을 기준으로 삼을 수 있습니다(예: 트리 삽입).
createItem(item: any, addOpts?: AddRowOptions) => void—addItems와 동일한 위치 지정 방식으로 새 행 하나를 추가합니다.
removeItems(ids: any[]) => void—row-id 값으로 행을 제거합니다.
getChangedItems() => any[]—생성/수정/삭제 상태가 대기 중인 행만 반환합니다.
setPaging(paging: PagingInfo) => void—푸터/페이징 UI가 사용하는 페이징 상태를 갱신합니다.
getItemById(rowId: RowId) => any—row id로 행을 조회합니다.
getItemsByIds(rowIds: RowId[]) => any[]—row id들로 행들을 조회합니다.
getItemsByIndexs(indexs: number[]) => any[]—화면상 행 인덱스로 행 데이터를 조회합니다.
selectRowById(rowId: RowId, opts: RowSelectOptions) => void—행 id로 행을 프로그래밍 방식으로 선택합니다. `opts.scrollIntoView`로 자동 스크롤 여부를 제어합니다.
getSelection(numberFieldSummary?: boolean) => any—selectionMode에 따른 현재 선택 데이터(및 선택적 숫자 필드 요약)를 반환합니다.
getSelectedRows() => any[]—현재 선택된 행 객체들을 반환합니다.
getSelectedRowIds() => RowId[]—현재 선택된 행 id들을 반환합니다.
getCheckedItems(names?: string | string[]) => any—체크된 행 데이터를 반환하며, 필요하면 주어진 필드명으로 제한할 수 있습니다.
getCheckedIds() => any[]—체크된 행 id들을 반환합니다.
getCheckedItemByName(name: string) => any[]—현재 체크된 모든 행에서 지정한 필드의 값을 반환합니다. 예: name이 'id'이면 체크된 행들의 id를 반환합니다.
setAllCheckedItems(checked: boolean) => void—모든 행을 체크하거나 체크 해제합니다.
setCheckedItemByValue(name: string, values: any) => void—`name` 필드가 `values`와 일치하는 행의 체크 상태를 설정합니다.
addCheckedItemByValue(name: string, values: any) => void—`name` 필드가 `values`와 일치하는 행의 체크 상태를 추가합니다.
unCheckedItemByValue(name: string, values: any) => void—`name` 필드가 `values`와 일치하는 행의 체크 상태를 해제합니다.
setTheme(themeName?: ThemeType | '') => void—런타임에 그리드 테마('light' | 'dark')를 전환합니다. 인자 없이 호출하면 그리드별 테마 지정을 해제하고 다시 data-daracl-theme 속성을 따릅니다.
setStyle(styleName: BodyStyle) => void—런타임에 body 스타일 프리셋을 전환합니다.
setSize(width: number, height: number) => void—그리드 크기를 프로그래밍 방식으로 조정합니다.
expandAll() => void—모든 트리 노드를 펼칩니다(트리 모드에서만).
collapseAll() => void—모든 트리 노드를 접습니다(트리 모드에서만).
search(searchText: string, opts: SearchMode) => any—SearchOptions와 동일한 형태의 옵션으로 프로그래밍 방식으로 검색을 실행합니다.
copyData() => void—현재 선택 영역을 클립보드로 복사합니다.
changeContextMenuHeader(label: string) => void—런타임에 컨텍스트 메뉴 헤더 라벨을 갱신합니다.
getToolbarValues() => any—현재 툴바 아이템 값을 읽습니다.
setToolbarValues(values: any) => void—툴바 아이템 값을 씁니다.
getGridHeight() => number—그리드의 현재 렌더링된 높이(px)를 반환합니다.
hideLayer() => void—열려 있는 플로팅 레이어(드롭다운/팝업 등)를 닫습니다.
setFocusOut() => void—그리드가 포커스를 잃었을 때와 동일한 focusout 처리(예: 열린 레이어 닫기)를 실행합니다.
destroy() => void—그리드 인스턴스와 그 DOM/리스너를 정리합니다.
