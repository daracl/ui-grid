API 레퍼런스

RendererInfo (View / Edit)

field.renderer(보기)와 field.editRenderer(편집)의 기본 형태이며, constantRenders.ts에 등록된 구체적인 `type` 값들을 포함합니다.

소스: src/types/RendererInfo.d.ts, src/constantRenders.ts, src/constantStyles.ts

타입

interface RendererInfo {
  type: string;
  variant?: string;
  click?: OptionCallback;
}

interface ViewRendererInfo extends RendererInfo {
  tooltip?: string;
  refValue?: OptionCallback | any;
  rule?: { minLength: number; maxLength: number; minimum: number; maximum: number };
}

interface EditRendererInfo extends RendererInfo {
  customOptions?: any;
  required?: boolean;
  regexpType?: RegexpType;          // 'email' | 'url' | 'alpha' | 'alpha-num'
  rule?: {
    minLength: number; maxLength: number;
    minimum: number; exclusiveMinimum: boolean;
    maximum: number; exclusiveMaximum: boolean;
  };
  different?: { field: string; message: string };
  identical?: { field: string; message: string };
  defaultValue?: string;
  listItem?: ValuesInfo;
  validator?: OptionCallback;
  change?: OptionCallback;
  trueValue?: string | boolean;
  falseValue?: string | boolean;
  showLabel?: boolean;
  iconStyle?: string;
  icon?: string;
}

속성

속성타입기본값설명
typestring—렌더러 타입 키입니다. View: 'text' | 'number' | 'password' | 'dropdown' | 'bar' | 'button' | 'html' | 'image' | 'link' | 'sparkline' | 'sparklineBar' | 'tree' | 'custom'. Edit: 'text' | 'number' | 'password' | 'textarea' | 'dropdown' | 'checkbox' | 'switch' | 'range' | 'date' | 'custom'.
variant?string—이를 지원하는 렌더러를 위한 미리 정의된 스타일 변형입니다. 현재는 'switch'만 지원하며 'box' | 'round'가 있습니다(constantStyles.ts의 RENDERER_VARIANTS 참고).
click?OptionCallback—클릭 가능한 렌더러(예: button, link)를 위한 클릭 핸들러입니다.
listItem?ValuesInfo—dropdown/choice 계열 렌더러를 위한 옵션 목록입니다: { labelField, valueField, list, multiple, orientation, includeAllOption }.
refValue?OptionCallback | any—View — 보기 렌더러(bar, button, dropdown, html, image, link, sparkline)가 표시할 내용을 결정할 때 쓰는 참조 데이터입니다. 함수는 `(field, value, rowItem)`로 호출되고, 문자열은 `{ label }`로 사용되며, 객체는 셀 값으로 조회합니다(`refValue[value]`).
tooltip?string—View — 툴팁 텍스트입니다. 타입에는 선언되어 있지만 현재 렌더러에서는 아직 사용하지 않습니다.
trueValue?string | booleantrueEdit — checkbox/switch가 켜졌을 때 기록되는 값입니다.
falseValue?string | booleanfalseEdit — checkbox/switch가 꺼졌을 때 기록되는 값입니다.
showLabel?booleanfalseswitch 계열 렌더러 안에 on/off 라벨 텍스트를 표시합니다.
change?OptionCallback—Edit — 편집 값이 변경될 때 `{ field, evt, item, value }`와 함께 호출되며, false를 반환하면 변경이 취소됩니다.
validator?OptionCallback—편집 렌더러를 위한 커스텀 유효성 검증 함수입니다.
required?boolean—편집 렌더러를 유효성 검증에서 필수로 표시합니다.
regexpType?'email' | 'url' | 'alpha' | 'alpha-num'—내장 정규식 유효성 검증 프리셋입니다.
rule.minLength?number—Edit — 유효성 검증 시 확인하는 최소 문자열 길이입니다.
rule.maxLength?number—Edit — 유효성 검증 시 확인하는 최대 문자열 길이입니다.
rule.minimum?number—최소 숫자 값입니다. Edit: 유효성 검증에 사용되고 number 입력의 min으로 설정됩니다. View: 'bar' 렌더러의 하한값입니다(기본 0).
rule.maximum?number—최대 숫자 값입니다. Edit: 유효성 검증에 사용되고 number 입력의 max로 설정됩니다. View: 'bar' 렌더러의 상한값입니다(기본 100).
rule.exclusiveMinimum?boolean—Edit — true이면 값이 rule.minimum보다 커야 합니다(같으면 실패).
rule.exclusiveMaximum?boolean—Edit — true이면 값이 rule.maximum보다 작아야 합니다(같으면 실패).
different.field?string—Edit — 같은 행의 다른 필드명입니다. 이 셀 값이 해당 필드 값과 같으면 유효성 검증에 실패합니다.
different.message?string—Edit — `different` 검사가 실패했을 때 사용하는 메시지입니다.
identical.field?string—Edit — 이 셀 값과 비교할 같은 행의 다른 필드명입니다.
identical.message?string—Edit — `identical` 검사가 실패했을 때 사용하는 메시지입니다.
defaultValue?string—Edit — 타입에는 선언되어 있지만, 내장 렌더러는 대신 field.defaultValue를 사용합니다.
customOptions?any—Edit — 커스텀 편집 렌더러에 그대로 전달되는 자유 형식 옵션입니다. 내장 렌더러에서는 사용하지 않습니다.
icon?string—내장 아이콘 세트의 아이콘 이름이며, 툴바 버튼 렌더러에서 사용합니다.
iconStyle?string—툴바 버튼 아이콘의 CSS 클래스이며, `icon`이 없을 때 사용합니다.
