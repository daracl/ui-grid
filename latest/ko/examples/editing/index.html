Editing

GridOptions.editable는 인라인 셀 편집을 켭니다. 각 필드는 자신만의 editRenderer(number, dropdown, switch 등)를 선택할 수 있습니다.

Editable

미리보기

소스 코드

const grid = DaraGrid.create(el, {
  editable: true,
  selectionMode: 'cell',
  fields: [
    { name: 'name', label: 'Name', width: 140 },
    { name: 'age', label: 'Age', width: 80, editRenderer: { type: 'number' } },
    {
      name: 'department',
      label: 'Department',
      width: 160,
      editRenderer: {
        type: 'dropdown',
        listItem: {
          labelField: 'label',
          valueField: 'value',
          list: [
            { label: 'Platform', value: 'Platform' },
            { label: 'Design', value: 'Design' },
          ],
        },
      },
    },
    { name: 'active', label: 'Active', width: 90, renderer: { type: 'switch' }, editRenderer: { type: 'switch' } },
  ],
  items,
});
