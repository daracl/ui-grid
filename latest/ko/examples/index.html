기본
Basic Grid

가장 작은 형태로 동작하는 그리드입니다: 컬럼 정의 목록(`fields`)과 행 데이터(`items`)만 있으면 됩니다.

선택
Selection

GridOptions.selectionMode는 셀/행을 어떻게 선택할지 제어합니다. 아래에서 모드를 바꿔가며 차이를 확인해 보세요.

편집
Editing

GridOptions.editable는 인라인 셀 편집을 켭니다. 각 필드는 자신만의 editRenderer(number, dropdown, switch 등)를 선택할 수 있습니다.

정렬
Sorting

header.sort.enabled는 그리드 전체 모든 컬럼에서 정렬 가능한 헤더 동작을 켭니다. 컬럼이 이 스위치와 별개로 field.sort: true를 설정해서 개별적으로 opt-in할 수도 있습니다.

페이징
Paging

GridOptions.paging은 클라이언트 사이드 페이징 상태를 담고, footer.paging은 푸터 바에 페이지 범위 텍스트를 렌더링합니다.

푸터
Footer

FooterOptions는 페이징 표시와 선택 요약을 같은 바에 함께 보여줍니다. 셀을 선택해서 요약이 갱신되는지 확인해 보세요.

툴바
Toolbar

ToolbarOptions.items는 그리드 위에 좌/우 아이템 그룹의 행들을 배치합니다 — 버튼, 드롭다운, 텍스트, 검색 등.

트리
Tree Grid

GridOptions.tree는 그리드를 트리 그리드로 전환합니다. 이 예제는 isFlatData: true와 함께 평면 행(id/parentId), expandDepth, defaultExpandedIds를 사용합니다.

행 이동
Row Move

body.rowMove는 드래그 앤 드롭 행 재정렬을 활성화합니다. dragStart / dragOver / drop / dragEnd는 각각 이동 중인 행과 드롭 위치를 전달받습니다.
